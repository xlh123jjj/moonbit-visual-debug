# Submission Checklist

- Public repository contains complete source history.
- Default branch is `main`.
- License is Apache-2.0, an OSI-approved license.
- README explains project goal, scope, install, usage, tests, and boundaries.
- `docs/sources.md` explains source ownership and ecosystem-overlap check.
- CI runs MoonBit install, format check, warning-denied check, tests, and interface generation.
- `pkg.generated.mbti` files are committed.
- Demo CLI and example workflow are present.
- No generated placeholder contributor names are used.
- Git author is the repository owner account.
