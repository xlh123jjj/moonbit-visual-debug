# Changelog

## 0.2.0

- Added validated COCO categories and annotations import/export.
- Added conversion from COCO annotations to named visual detections.
- Added benchmark coverage for 256-overlay SVG and PNG rendering.
- Strengthened detection-matching and PNG block boundary tests.

## 0.1.0

- Added core geometry, color, overlay, and document models.
- Added SVG and HTML report rendering.
- Added RGBA canvas and deterministic PNG encoding.
- Added detection comparison and error-layer generation.
- Added demo CLI, tests, and generated MoonBit interface files.
